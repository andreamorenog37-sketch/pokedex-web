Instrucciones de Instalación
Clonar o descargar el repositorio en su máquina local utilizando el sistema de control de versiones o descargando el código fuente en formato ZIP.

Abrir el directorio del proyecto en un entorno de desarrollo integrado, preferiblemente Visual Studio Code, para gestionar los archivos de manera eficiente.

Verificar la estructura de archivos para asegurar que los scripts de JavaScript, las hojas de estilos CSS y el modelo exportado de inteligencia artificial se encuentren en los directorios correspondientes.

Instrucciones de Ejecución
Iniciar el servidor local utilizando la herramienta Live Server integrada en Visual Studio Code. Para ello, haga clic derecho sobre el archivo principal index.html y seleccione la opción "Open with Live Server".

Acceder a la aplicación a través del navegador web predeterminado, el cual abrirá automáticamente la dirección local correspondiente (por ejemplo, [http://127.0.0.1:5500](http://127.0.0.1:5500)).

Interactuar con el sistema permitiendo el acceso a la cámara web cuando el navegador lo solicite, para que el modelo de reconocimiento procese la imagen en tiempo real y consulte la API de Pokémon.
